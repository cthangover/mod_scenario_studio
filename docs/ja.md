# Scenario Studio — ゲームの実行中にシナリオをデバッグし、その場で編集する

Scenario Studio は、実行中のゲームの脇に開くドックで、いまどのシナリオが再生され、どの行が画面に出ているかを示します。ダイアログを一時停止し、一行ずつステップ実行し、ブレークポイントで止め、次の行を付け替え、ゲームの状態を巻き戻してシナリオを再開始し、その場でシナリオを書き換えられます——そして変更はすぐにゲームの中に現れます。

モードは二つ。**初心者**モードは物語の瞬間をシンプルなブロックで示し、**作者**モードは行番号付きのシナリオテキストを示します。

## 開き方

Developer Tools ツールセットを含むゲーム（メカニクス *Scenario Studio*）には、ツールバーに**スタジオ**ボタン——羽根ペン——があります。起動フラグ `--studio` を付けると、開始時にドックが開きます。以下の画像は Cthangover の台所でのものです。編集はテストレイヤーに入れてあり、ゲーム本来のファイルには触れていません。

## 初心者モード

![台所と、右側に初心者モードのスタジオドック: シーン home_kitchen、シナリオ home_kitchen_cooking、レイヤーのバッジ。「いま画面に」の下に行「新しい行」と質問「台所として整えられた部屋」、回答は「出る」（シーン home_vestibule へ）、「料理する」（行動 toggle_cooking_workbench）、新しい回答の三つで、それぞれ「行き先を選ぶ」と「編集」付き。ボタン「+ 質問の前に行」「+ 回答」。下部に「この変更が影響するもの」（目標レイヤー）と「適用」。](assets/studio-novice.jpg)

**現在**タブは画面の瞬間を示します: 行、質問、そして各行き先付きの回答すべて。**編集**はテキストを直し、**行き先を選ぶ**は回答の行き先（ラベル、別のシーン、終わり）を変え、**+ 行**と**+ 回答**はその瞬間に足します。変更ごとに、**この変更が影響するもの**にどの MOD かレイヤーに書かれるかが表示されます。

## 作者モード、一時停止、ブレークポイント

![作者モードのドック: トランスポートバーに「一時停止」「ステップ」「続行」「リソース」「再開始」。home_kitchen のシナリオテキストの 6 行目——select「台所として整えられた部屋」——に赤いブレークポイントの点と現在行の ▶ マーカー。その下に「9 行目のあと」と「+ 行」「+ 選択肢」「+ シーンへ移動」、そして目標レイヤー my_studio。](assets/dock-breakpoint.jpg)

- **一時停止**は次の行の前でダイアログを止め、**ステップ**は一行だけ実行し、**続行**はそのまま進めます。
- 余白をクリックすると**ブレークポイント**が付きます: ダイアログはその行の前で止まります。
- **▶** マーカーを別の行へドラッグすると、その行が次に実行されます。
- **+ 行**、**+ 選択肢**、**+ シーンへ移動**は現在行のあとに追加し、**テキストを編集**はシナリオ全体を編集します。

## 適用と再開始

**適用**は変更を書き込み、シナリオを再開始します。ここでは質問の前に「新しい行」を足しました。適用後、それが画面に出ています:

![適用後のドック: 画面には「新しい行」、状態は「「my_studio」に適用し、巻き戻してシナリオを再開始した」。](assets/dock-applied.jpg)

**再開始**では選べます: ロールバックなしでもう一度、**状態を巻き戻して**もう一度（フラグ、持ち物、時計などがシナリオ開始時の状態へ戻ります）、シーンを入り直す、現在のラベルから続ける。

## 状態の確認

![状態タブ: 「値を変えて別の分岐を試せます」、時計は 24 日 23:00。](assets/dock-state.jpg)

**状態**タブはゲームの状態を持ち主ごとに示します: 時計、進行中のダイアログの変数、シナリオが参照するクエスト、インベントリ、そしてどのシナリオがすでに実行されたか。変数、持ち物の数、クエストの状態は変えられ（Enter でゲームに書き込まれます）、別の分岐を試せます。**シーン**タブは現在のシーンのシナリオ一覧、**マップ**はシーンとその間の経路（新しい背景のドロップ先）を示し、**ログ**は何が起きたかを記録します:

![ログタブ: home_kitchen に入った、home_kitchen_cooking が始まった、編集「+6 → my_studio」、再開始、「ブレークポイント、6 行目」、「次の行を 5 へ移動」、「home_kitchen のチェックポイント」。](assets/dock-log.jpg)

## 変更の書き込み先

- フォルダーとしてインストールされた MOD は、その場で書き換えられます。
- それ以外の変更は、ゲームの**スタジオレイヤー**（`user://studio/<game>`）に入ります。レイヤーはどの MOD よりも優先され、MOD には触れません。レイヤーは新しい MOD として書き出せ、それをゲームのコレクションに追加します。
- **リソース**は、ゲームの実行中に MOD やレイヤーの `backgrounds/` フォルダーへ置かれた背景を読み直します。その背景からなら、マップタブから新しいシーンを作れます。

## うまくいかないとき

1. **スタジオボタンがない。** そのゲームのコレクションにスタジオが入っていません。Developer Tools ツールセットを追加するか、`--studio` を付けて起動してください。
2. **ステップが何もしない。** ダイアログが回答を待っています: 先に一つ選んでください。
3. **他のプレイヤーに変更が見えない。** スタジオレイヤーの変更は、この PC のこのゲームの中にとどまります。共有するにはレイヤーを MOD として書き出してください。
